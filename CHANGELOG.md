# Changelog

All notable changes to this module are documented here.

## 1.0.0 - 2026-07-29

- Create public, private, and isolated database subnets across two to six Availability Zones.
- Add configurable `none`, `single`, and `per_az` NAT gateway modes.
- Add an optional RDS DB subnet group.
- Add optional CloudWatch-backed VPC Flow Logs.
- Harden the default VPC security group by default.
- Add native Terraform tests and a complete three-AZ example.
